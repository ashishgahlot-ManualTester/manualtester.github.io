BUG TITLE

Clickable area of Cross (Remove) icon not clickable on "Add another option" field

Severity

3

Low

Category

UI

Status

Reported

Date

22-Jun-2026

🌐 Environment

Browser Chrome
Operating System Windows 10
Device Desktop

🔐 Pre-Requisite

  • User must be logged into YouTube.
  • Community Post creation page should be open.
  • Text Poll option should be selected.

📝 Steps to Reproduce

1 Open YouTube.
2 Navigate to Community Post.
3 Select Text Poll.
4 Click "Add another option".
5 Hover over the Remove icon.
6 Observe the issue.

✅ Expected Result

Cross (Remove) icon should be completely clickable and remove the corresponding poll option when clicked.

❌ Actual Result

Only a small portion of the Cross (Remove) icon is clickable, making it difficult for users to remove the poll option.

💡 Notes

  • Issue occurs consistently.
  • Observed in both Chrome and Microsoft Edge.
  • Clickable target appears smaller than the visible icon boundary.
  • May affect users attempting to quickly remove poll options.
