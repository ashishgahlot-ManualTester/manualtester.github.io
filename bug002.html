Few details are missing in “Download Amazon Shopping App” page at bottom for all languages (Tamil, Telugu, Kannada, Malayalam, Marathi and Bangla) except Hindi and English

Date

10/6/2026

Severity

3

Category

Localization

Status

Submitted

🖥️ Environment

Browser: Chrome

Operating System: Windows 10

Device: Desktop

🔐 Pre-Requisite

User must be logged into Amazon.

🔄 Steps to Reproduce

  1. Navigate to amazon.in
  2. Hover on Language icon on top header of page.
  3. Select any language except Hindi and English.
  4. Click on "Download Amazon App" button visible on the right side of the menu bar.
  5. Select Hindi language.
  6. Scroll to the bottom and observe the text is visible in Hindi.
  7. Change language again except English.
  8. Observe the text is missing for Tamil, Telugu, Kannada, Malayalam, Marathi and Bangla.

✅ Expected Result

"Kya aapko Jaankari chahiye, Yahan Dekhein" text should be visible in the selected language.

❌ Actual Result

"Kya aapko Jaankari chahiye, Yahan Dekhein" text is missing for Tamil, Telugu, Kannada, Malayalam, Marathi and Bangla languages. The text is only visible in Hindi and English.

💡 Notes

  • Issue occurs consistently.
  • Observed in both Chrome and Microsoft Edge.
